# Liga de Leyendas — Guía visual

## Paleta principal
- `#9A7425` — dorado principal: pestañas activas, iconos destacados, CTA principal.
- `#6B5019` — dorado oscuro: hover, texto de acción, estados activos secundarios.
- `#F4F2ED` — fondo general y superficies suaves.
- `#FFFFFF` — tarjetas, paneles, tablas y cabeceras.
- `#E9E8E5` — bordes, separadores, filas alternas y fondos neutros.
- `#181818` — texto principal y datos.
- `#686868` — texto secundario, ayudas y metadatos.
- `#252525` — navegación oscura, títulos fuertes y superficies oscuras puntuales.

## Colores semánticos
Se permiten colores externos solo cuando comunican un estado que necesita reconocimiento inmediato: victoria/éxito, derrota/error, tarjeta amarilla, tarjeta roja, advertencia o estados de competición. No deben usarse como parte de la identidad general, navegación, fondos estructurales o decoración.

## Reglas de componentes
- Fondo de página: `#F4F2ED`.
- Tarjetas/paneles: `#FFFFFF`, borde `#E9E8E5`, radio 12–14px, sombra muy suave.
- Navegación principal activa: dorado `#9A7425` / `#6B5019`, nunca azul.
- Texto principal: `#181818`; secundario: `#686868`.
- Tablas: cabecera crema/neutra, separadores `#E9E8E5`; no usar cabeceras azules.
- Inputs/filtros: blanco, borde neutro, foco dorado.
- Gráficos estructurales: dorado + neutros. Usar rojo/verde solo cuando el dato sea semánticamente negativo/positivo.
- Los módulos Clubes, Competiciones, Partidos, Estadísticas, Historial y Récords comparten el mismo sistema visual.
